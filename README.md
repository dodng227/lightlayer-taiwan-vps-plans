## 台湾两条线路的实际差异

官方把台湾机房分成两条线：**Premium 是 CN2 + Mainland BGP + International BGP**，面向大陆用户做低延迟和稳定性；**Global 只有 International BGP**，面向大陆以外和台湾本地用户。两条线价格一样，配置一样，差的是路由。

判断方法很直接，官方给了两个测试 IP，自己 ping 一遍比看任何测评都准：

- Premium：`46.8.124.242`
- Global：`46.8.126.64`

2026 年 10 月的一份第三方测评跑了 Premium 线路的三网路由，结果值得注意。去程方面，上海电信走 CN2 经香港到台湾，上海联通走 AS10099（CUG）经香港，上海移动走 CMIN2 到台湾。回程广州电信走 CN2（CTGNet）经香港直连回国，广州联通走 CN2 经香港到广州再转联通 4837，广州移动走 CMI 经香港直连回国。三网都是各自骨干直连，中间在香港拐了一下。

同一份测评里还有个细节：路由第一跳落在菲律宾马尼拉（AS54801 zillion.network，约 2ms）才转香港。也就是说这个 IP 的骨干接入并不是直连台湾本地，而是从马尼拉接入再回到香港。这不影响大陆访问速度，但解释了为什么它的 IP 归属地信息显示的不是台湾。

Global 线路的第三方描述是：电信和联通回程走 NTT / retn / lumen 绕日本美国，移动回程 CMI 直连。做大陆业务选 Global 属于给自己找麻烦，省不下钱。

## 常见问题

**续费会不会涨价？**
官方活动页写明续费同价，2024 到 2026 年的多次价格记录也一致。但促销码和闪购活动会变，续费价请以你下单时页面上的说明为准。

**能用支付宝吗？**
能。目前支持 PayPal 和 Alipay。

**10Mbps 够用吗？**
看用途。一个日 PV 几千的 WordPress 站点，10Mbps 够。同时在线看视频、跑大文件传输，不够。实测 9.71Mbps 已经顶到上限了。

**5Mbps 不限流量和 10Mbps / 1TB 怎么选？**
先算一下每月流量。1TB / 30 天 ≈ 34GB/天，绝大多数个人站跑不到这个量。跑不到就选 10Mbps / 1TB，带宽翻倍。只有明确知道自己月流量会超过 1TB、又不在乎速度的，才选 5Mbps 不限流量。

**能解锁 Netflix 和 Disney+ 吗？**
这个 IP 的实测结果是 Netflix 只有原创内容，Disney+ 直接不可用。别为解锁流媒体买这台。

**有 DDoS 防御吗？**
没有。
